# PyPath – Python learning PWA

1. Supabase > SQL Editor: run the `sql-1…` files in order (each is small enough to copy) (tables, security rules, 17 lessons).
2. Put Project URL + anon key in `config.js`.
3. Run locally (PWA needs http, not file://): `python -m http.server 8000` then open http://localhost:8000
4. Deploy free: Netlify / Vercel / GitHub Pages (upload this folder). Open the https link on phone > "Add to Home screen".
